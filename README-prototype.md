# Городской маршрут

Играбельный браузерный прототип транспортной стратегии по концепции Алима. Русский интерфейс, изометрический город Верхнереченск, управление мышью и касаниями. Без сборки и обязательных внешних библиотек.

## Запуск

```sh
python serve.py
```

Откройте **http://localhost:8000**. Также можно открыть `index.html` напрямую в браузере, поддерживающем локальные HTML-файлы. Для установки на домашний экран и офлайн-кеша нужен запуск через localhost или HTTPS; на HTTP по локальной сети игра работает без service worker. Сторонний шрифт необязателен: без сети используется системный.

**Без сервера:** откройте `Городской маршрут.html` в браузере. В нём встроены стили, код и значок; сеть не требуется. Чтобы обновить эту версию после изменений, выполните `python build.py`.

## Игра

- Начало: 85 000 ₽, 5 000 жителей, две маршрутки. Одна уже обслуживает Вокзальный маршрут, другая в резерве.
- Нажмите «Создать маршрут», затем 2–12 остановок. Открытие: 3 000 ₽ + 500 ₽ за остановку. Если свободных машин нет, автоматически покупается маршрутка за 18 000 ₽; цена показана до подтверждения.
- Маршрутки вмещают 12 пассажиров, ходят по улицам в обе стороны, берут плату при посадке. Пассажир садится только на линию со своей конечной остановкой; пересадки в этом прототипе не моделируются.
- Нажмите маршрут для статистики и добавления машин. В автопарке можно покупать, назначать, снимать и ремонтировать машины. В финансах — менять тариф и управлять кредитом.
- Включите «Спрос», чтобы увидеть очереди. Перемещение карты — перетаскивание, масштаб — колесо, кнопки +/− или щипок двумя пальцами. Пробел — пауза. Во время строительства, диалогов и в фоновой вкладке симуляция приостановлена.
- Три задания: подключить больницу, доставить 100 пассажиров, затем вырастить город до 6 000 жителей и доставить 300 пассажиров. Для финала также нужно ответить Грачу в «Истории». Письмо появляется после 80 доставленных пассажиров.
- Решение по Грачу меняет бюджет, доверие, довольство и правила закрытия маршрутов. После финала доступна свободная игра. Банкротство наступает при бюджете ниже −10 000 ₽ одновременно с доверием ниже 20%.
- Автосохранение каждые 10 секунд, после действий и при уходе из игры. Данные хранятся только в браузере на этом устройстве. Очищение данных браузера удалит город. На другом адресе/порту сохранение отдельное.

## Границы прототипа

Это первая глава, а не полная Android-игра из PDF. Карта нарисована в Canvas 2D с изометрическими объёмными зданиями. Пока нет настоящего 3D, вращения камеры, метро, автобусов, остальных глав и полного набора событий. Есть снегопад, ярмарка, рост города, износ, экономика и одна сюжетная развилка. APK не собирается: Android SDK и Gradle-проект не входят в эту версию.

## Проверка симуляции

```sh
python -m unittest discover -s tests -v
```

Для тестов нужен Node.js или QuickJS в PATH (либо путь в переменной `JS_RUNTIME`). Python-зависимостей нет. Тесты исполняют тот же `engine.js`, который использует игра, проверяют бюджет, поездки, задания, договор, кредит и сохранение, а также обработчики интерфейса с имитацией DOM/Canvas. Визуальная проверка на реальном браузере/Android выполняется отдельно.
